EYE OF THUNDERA — GUIA DO USUÁRIO
Atualizado em 16/10/2026

O Eye of Thundera é um assistente de conversa e pesquisa com interface escura. Ele usa Python e uma interface HTML dentro de uma janela pywebview.

COMO ABRIR
Na Área de Trabalho, dê duplo clique em Eye of Thundera. O atalho abre o programa em D:\Projetos\Eye of Thundera. Se a janela estiver aberta mas não responder, feche-a e abra o atalho novamente; se continuar, peça para verificar o arquivo de erro antes de reinstalar qualquer coisa.

PRIMEIRO USO
1. Abra Configurações > Chaves.
2. Cole sua chave do provedor desejado no campo correspondente.
3. Use o botão Testar, quando disponível, e clique em Salvar.
4. Digite a pergunta na caixa inferior e aperte Enter ou clique no botão de enviar.

Nunca compartilhe uma chave de API em mensagens, capturas de tela ou logs.

TELA PRINCIPAL
- Nova conversa: começa uma conversa nova.
- Conversas: lista e busca no histórico; use o menu da conversa para opções disponíveis.
- Configurações: abre as abas Memória, Conversa, Chaves e Ajuda.
- Web: alterna entre pesquisa automática, sempre e desligada.
- Pesquisa séria: liga/desliga o modo de pesquisa profunda para a próxima pergunta.
- Privada: inicia uma conversa que não deve ser salva no histórico nem usada para aprender memória.
- Resumo do dia: pede um resumo das notícias atuais.
- Microfone: clique para começar a gravar e clique novamente para parar. O texto transcrito aparece na caixa para revisão antes do envio.
- Soltar um arquivo de texto compatível na janela pode carregar seu conteúdo para a caixa de pergunta. Confira o conteúdo antes de enviar.

CONFIGURAÇÕES
- Memória: veja, organize, edite ou exporte os fatos guardados pelo assistente. Confira antes de apagar.
- Conversa: preferências de contexto, pesquisa, corretor e voz.
- Chaves: configure os provedores e serviços de reserva. Os campos de chave devem permanecer protegidos.
- **Personalização**: escolha entre 5 temas pré-definidos para a interface (Clássico Dark, Purpurina, Amethyst, Ocean, Forest). As escolhas são salvas no config.json e aplicadas imediatamente.
- Ajuda: informações de uso e atalhos.

ATALHOS
- Enter: envia a pergunta.
- Shift+Enter: quebra a linha.
- Ctrl+N: nova conversa.
- Ctrl+F: buscar conversas.
- Ctrl+M: microfone.
- Ctrl+S: salvar a última resposta como texto.
- Ctrl+D: resumo do dia.
- Ctrl+B: mostrar ou esconder a barra lateral.
- Ctrl+Shift+S: pesquisa séria.

DADOS E PRIVACIDADE
Configurações, histórico e memória ficam no perfil local do Windows, em %LOCALAPPDATA%\Eye of Thundera. O programa envia a pergunta e o contexto necessário ao provedor de IA escolhido quando você pede uma resposta; não trate conversas privadas como substituto para não enviar informações sensíveis a serviços externos. Faça backup antes de alterações importantes.

SE ALGO NÃO FUNCIONAR
1. Feche e abra novamente o atalho.
2. Se os cliques continuarem sem resposta, não reinstale nem apague dados. Informe o que clicou e peça para consultar %LOCALAPPDATA%\Eye of Thundera\erro.log.
3. Não envie chaves de API junto com o log.
